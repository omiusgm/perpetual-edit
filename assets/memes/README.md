# Reaction assets

`starter/` contains original schematic cat cards generated from OpenCV drawing
primitives. They are part of the repository's MIT-licensed starter experience;
they are not AI-generated and do not copy a known meme.

For your own reaction pack, create `assets/local/reactions/` and point an
ignored `config.local.json` at those files. Only add media that you have the
right to use. The `assets/local/` tree is ignored intentionally.
